# Ресерч продуктов SCOPE.GG

Цель: зафиксировать, какие продукты/фичи SCOPE.GG уже существуют для помощи игрокам CS2 —
чтобы в анализе конкретного игрока ссылаться на реальные инструменты компании (а не придумывать).

Confidence: medium. Источники — прямой фетч scope.gg/grenade-predictor и главной страницы
(high/medium-high confidence), WebSearch сниппеты (medium, не все перепроверены прямым фетчем).
esports.gg review — 403, не прочитан, не учтён в выводах.

## 1. Существующие продукты (подтверждено)

### Grenade Predictor / CS2 Lineups
- URL: https://scope.gg/grenade-predictor
- Интерактивная 2D тактическая карта по всем конкурентным картам (обе стороны T/CT).
- Лайнапы smoke / flash / HE / molotov, включая one-way smokes.
- Короткие видео-гайды на каждый лайнап + copy-paste `setpos` координаты для практики в игре.
- Отдельные лайнапы под 64-tick и 128-tick серверы.
- Бесплатно без логина, часть функций — после регистрации.
- Доп. страница: https://scope.gg/guides/grenades_in_your_match_en/ — как разбирать свои
  гранатные лайнапы по матчам.

### CS2 Dashboard (app.scope.gg)
- Веб-дэшборд, привязка Steam/FACEIT аккаунта.
- Метрики: KDR, ADR, HLTV Rating 2.1, accuracy/hit%, headshot rate, utility/grenade stats.
- "My Progress" — тренд метрик за последние 30 матчей.
- Покрывает и Matchmaking, и FACEIT-матчи (не только официальные/HLTV игры).

### Demo Viewer
- 2D replay с тактическими оверлеями.
- "Performance review" — разбор ошибок по карте, позиционные рекомендации.

### Comparing tool
- Head-to-head сравнение статистики с другим игроком.

### Прочее на платформе
- Tactical board — app.scope.gg/strategy (стратегии/заготовки).
- Clips — автозапись хайлайтов матчей.
- CS2 profile checker.
- Prematch analytics (скаутинг соперника перед матчем) — не подтверждено, free vs premium неясно.
- Wingman mode history — упомянут, детали не проверены.
- Discord поддержка на сайте.

## 2. Чего НЕТ (важно не приписывать)

- Нет отдельного **aim-trainer** (типа aim_botz клона) — есть только статистика accuracy/HS%
  в дэшборде, не интерактивная тренировка.
- Нет отдельного **movement/positioning trainer** — только обзор ошибок в Demo Viewer
  (performance review), не drill-инструмент.
- Нет подтверждённого браузерного расширения/overlay продукта.
- Пайплайн и состав premium/coaching-тира (цены, что входит) — не подтверждён.

## 3. Что из этого полезно для анализа одного игрока по утилити

| Проблема у игрока                                   | Инструмент для рекомендации           |
|-------------------------------------------------------|----------------------------------------|
| Нестабильные лендинги смоков (не заучен лайнап)       | Grenade Predictor (setpos, видео, tick-rate) |
| Высокий тимдамаг флешами / много пустых флешей        | Grenade Predictor + Demo Viewer (разбор конкретных раундов) |
| Низкий dmg/throw по HE                                | Grenade Predictor (стандартные HE-лайнапы) |
| Нужно отслеживать тренд метрик со временем            | CS2 Dashboard → "My Progress"          |
| Сверка с конкретным другим игроком/тиммейтом          | Comparing tool                         |

## 4. Гэпы / что перепроверить при углублении

- Премиум-тир и его состав (не подтверждено).
- esports.gg review (403 при фетче) — если нужны детали коучинга, искать альтернативный источник.
- Наличие браузерного расширения/overlay — не подтверждено ни в одну сторону.
